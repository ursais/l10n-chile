This module extends the Chilean localization (l10n_cl_edi) to provide automatic
CAF (Código de Autorización de Folios) management through SII web services.

**Features**:

* Query available CAF from SII web services
* Automatic monitoring of CAF usage
* Alert system when CAF folios are running low
* Integration with existing l10n_cl_edi CAF management

Configuration
=============

1. Go to **Accounting > Configuration > Chilean SII > CAF Monitors**
2. Create a new CAF monitor for each document type you want to track
3. Configure:
   - Document Type (e.g., Factura Electrónica 33)
   - Alert threshold (percentage or absolute number)
   - Users to alert
4. The system will automatically check CAF availability

Usage
=====

Manual CAF Query
----------------

1. Go to **Accounting > Configuration > Chilean SII > Query CAF**
2. Fill in:
   - Document Type
   - From Folio
   - To Folio
3. Click **Query CAF** to check availability in SII

Automatic Monitoring
--------------------

The system will automatically:

* Check CAF availability according to configured monitors
* Send alerts when thresholds are reached
* Track usage statistics on CAF files
